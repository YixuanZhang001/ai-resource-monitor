PROVIDERS · 配置
Dashboard 统计仅来自真实调用：配置 Key 后需把 AI 客户端 base_url 指向 http://127.0.0.1:8787/gateway/<provider> 发起调用才会产生数据。API Key 绝不写入 data/config.yaml（写了会被静默丢弃），仅存环境变量或本机凭据文件，不落事件库、不下发前端。
归因提示：想看到「哪个 Resource / Project / Client」用了多少，请让客户端带请求头 X-Monitor-Resource / X-Monitor-Project / X-Monitor-Client；或在 config.yaml 设置 providers.<name>.default_resource_id / default_project 作为无头流量的兜底。未配置时这类流量记为 Unknown（绝不猜测）。
自定义 OpenAI-compatible Provider：在 config.yaml 的 providers 段新增一项（任意名称）+ base_url + 启用，即复用同一套网关（无需第二套代理）。
